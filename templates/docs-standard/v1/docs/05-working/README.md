# 05-working

This lane holds non-canonical drafts.

## Rules

- Every file here must begin with `draft-`.
- Subfolders mirror canonical document classes.
- Drafts do not become authoritative until they are explicitly promoted.

## Promotion

1. move the draft into its matching canonical lane
2. remove the `draft-` prefix
3. update any indexes or links that should now point at the canonical file
