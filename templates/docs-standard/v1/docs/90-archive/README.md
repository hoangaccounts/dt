# 90-archive

Put retired or superseded docs here.

## Archive when

- a doc has been replaced
- two docs have been consolidated
- a filename changed materially and the old file should no longer be treated as active
- a rollout or plan doc is completed and no longer authoritative

## Archive requirements

An archived doc should clearly say:
- why it was archived
- what replaced it, if anything
- whether it remains useful only for historical context

## Important rule

Do not leave stale docs mixed beside active docs with similar names. That is one of the fastest ways to poison AI retrieval quality.
