# 40-decisions

Put cross-cutting rulings here.

## What belongs here

- architecture decisions
- product-structure decisions
- privacy/analytics posture decisions
- sync, offline, security, or module-boundary decisions
- other rulings that constrain multiple specs

## What does not belong here

- local feature requirements
- temporary implementation choices that do not matter outside one plan
- broad narrative product vision

## ADR rule

Keep ADRs short. They should record the decision and its consequences, not become mini-specs.
