# 20-libraries

Put reusable technical and domain-core specs here.

## What belongs here

- reusable headless domain cores
- cross-product packages or modules with stable contracts
- truth-owning reusable engines

## What does not belong here

- product-shell behavior
- host UI behavior
- project-only implementation details with no reuse case

## Admission rule

Do not create a library spec just because reuse sounds plausible. Create one when reuse is already real or intentionally committed.
